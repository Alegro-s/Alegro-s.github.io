# Портфолио Игоря Виноградова

Статический сайт без сборки: HTML, картинки и шрифты лежат в этой папке, внешние сервисы не нужны.

## Посмотреть у себя
Откройте `index.html` в браузере.

## Выложить на GitHub Pages
Дважды щёлкните «Опубликовать на GitHub.bat» в этой папке (при первом запуске он сам создаст ярлык на рабочем столе).
Скрипт установит git и GitHub CLI, попросит войти в GitHub, создаст репозиторий `Alegro-s.github.io`, включит Pages и опубликует сайт на https://alegro-s.github.io/.
После правок запускайте тот же ярлык: он сохранит изменения и обновит сайт.

## Выложить на свой сервер
1. У регистратора домена создайте две A-записи на IP сервера: `домен` и `www.домен`.
2. Дважды щёлкните `deploy\deploy.bat`.
3. Введите домен и сервер в виде `root@IP`. Скрипт запомнит их в `deploy\deploy-settings.json`.

Скрипт загрузит сайт в `/var/www/portfolio`, добавит отдельный сайт в nginx (другие проекты на сервере не трогаются) и выпустит бесплатный HTTPS-сертификат.
Если сертификат не выпустился, значит DNS ещё не обновился. Подождите час и запустите `deploy.bat` снова.

Повторный запуск обновляет сайт. Предыдущая версия остаётся в `/var/www/portfolio.old`.

## Что поменять
- Telegram: в `index.html` найдите `var TELEGRAM = ""` и впишите ник без @. Строка появится в контактах.
- Проекты: массив `var P = [...]` в конце `index.html`. Каждый проект — отдельный блок.
- Картинка для превью ссылки в мессенджерах: `og.jpg` (1200×630).
